    REGRAS DO AMBIENTE

    Limites & alertas.

    Defina as faixas aceitas e escolha quais sensores devem gerar alertas.

    Configuração persistente

    As alterações são salvas pela API no arquivo limites.json.

    Como os alertas funcionam

    Valores abaixo do mínimo ou acima do máximo ficam fora da faixa. Os próprios limites são aceitos. Na visão geral, ative os alertas no ESP monitor para a dashboard enviar os comandos.

    LDR: a faixa usa leitura bruta ADC, de 0 a 4095. Na montagem atual, uma leitura maior representa menos luz. Os limites iniciais são exemplos da prova de conceito.

    Dados antigos: a página indica leituras sem atualização há mais de 30 segundos e suspende novos comandos automáticos. Isso não desliga um alarme já recebido pelo ESP.
